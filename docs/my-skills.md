# 我的技能页面产品文档

## 一、背景与目标

当前 Skill 管理平台只有「Skill 市场」页面，展示的是已发布的市场技能。用户上传/创建自己的 Skill 后，没有地方查看、管理和继续编辑。

「我的技能」页面用于解决以下问题：

- 查看自己创建的所有 Skill
- 区分草稿、已发布、审核中等状态
- 继续编辑未发布的草稿
- 发布新版本的 Skill
- 下架或删除自己创建的 Skill

## 二、页面定位

- **入口**：左侧 Sidebar 增加「我的技能」菜单项
- **目标用户**：Skill 作者、内部开发者
- **核心价值**：让用户能够管理自己创建的 Skill 资产

## 三、入口设计

在左侧 Sidebar 的「Getting Started」分组中增加「我的技能」：

```
Getting Started
├── Overview
├── Skills            # Skill 市场（已发布技能）
├── 我的技能          # 新增
├── CLI
└── MCP server
```

同时，在 Skill 市场页面右上角增加快捷入口：

```
[上传 Skill]  [我的技能]
```

## 五、状态设计

每个 Skill 有以下状态：

| 状态 | 说明 | 可执行操作 |
|---|---|---|
| `draft` | 草稿，未发布 | 编辑、发布、删除 |
| `pending_review` | 审核中 | 撤销发布、查看详情 |
| `published` | 已发布 | 编辑、发布新版本、下架 |
| `deprecated` | 已下架 | 重新上架、删除 |

## 六、Skill 卡片信息

| 字段 | 说明 |
|---|---|
| 图标 | 默认图标或上传的图标 |
| 名称 | Skill 展示名称 |
| ID | 唯一标识 |
| 状态 | 草稿 / 审核中 / 已发布 / 已下架 |
| 当前版本 | 最新版本号 |
| 发布时间 | 首次发布时间 |
| 更新时间 | 最后更新时间 |
| 下载/使用次数 | 可选展示 |
| 操作按钮 | 编辑 / 发布 / 下架 / 删除 |

## 七、操作说明

### 7.1 编辑

- 草稿：进入 Skill 上传/编辑页，可以修改所有信息
- 已发布：进入编辑页，修改后保存为新版本草稿或直接发布新版本
- 审核中：不可编辑
- 已下架：需要先重新上架或进入编辑状态

### 7.2 发布

- 将草稿提交到市场
- 需要满足发布条件：
  - 元信息完整
  - 输入输出定义完整
  - 运行时配置正确
- 发布后状态变为 `published`

### 7.3 下架

- 已发布的 Skill 可以下架
- 下架后状态变为 `deprecated`
- 已安装的用户仍可继续使用，但无法新安装

### 7.4 删除

- 只有草稿状态和已下架状态可以删除
- 已发布或审核中的 Skill 不支持直接删除，需要先下架

## 八、筛选与排序

### 8.1 状态筛选

Tab 形式：

- 全部
- 已发布
- 草稿
- 审核中
- 已下架

### 8.2 搜索

按名称、ID 搜索

### 8.3 分类筛选

按能力类型、业务场景筛选

### 8.4 排序

- 最近更新
- 最近创建
- 名称 A-Z

## 九、数据流转

```
用户进入「我的技能」页面
    │
    ▼
前端调用 GET /api/skills?author=currentUserId
    │
    ▼
后端返回当前用户创建的 Skill 列表
    │
    ▼
前端按状态分组展示
    │
    ▼
用户执行操作：
    ├── 编辑 → 跳转到编辑页
    ├── 发布 → POST /api/skills/:id/versions/:version/publish
    ├── 下架 → PATCH /api/skills/:id (status -> deprecated)
    └── 删除 → DELETE /api/skills/:id
```

## 十、API 依赖

| 方法 | 路径 | 说明 |
|---|---|---|
| `GET` | `/api/skills?author={userId}` | 获取当前用户的 Skill 列表 |
| `GET` | `/api/skills/:id` | 获取 Skill 详情 |
| `PATCH` | `/api/skills/:id` | 更新 Skill 元数据 |
| `POST` | `/api/skills/:id/versions` | 创建新版本 |
| `POST` | `/api/skills/:id/versions/:version/publish` | 发布版本 |
| `PATCH` | `/api/skills/:id` | 下架 Skill（status -> deprecated） |
| `DELETE` | `/api/skills/:id` | 删除 Skill |

## 十一、与现有页面的关系

| 页面 | 作用 |
|---|---|
| Skill 市场 (`/skills`) | 查看所有已发布的市场 Skill |
| 我的 Skill (`/my-skills`) | 查看、管理自己创建的 Skill |
| 上传 Skill (`/skills/upload`) | 创建新的 Skill |
| Skill 详情 (`/skill/:id`) | 查看 Skill 详情，自己的 Skill 可编辑 |

## 十二、验收标准

- [ ] Sidebar 有「我的技能」入口
- [ ] 页面能展示当前用户创建的所有 Skill
- [ ] 支持按状态筛选（全部/已发布/草稿/审核中/已下架）
- [ ] 支持搜索和分类筛选
- [ ] 每个 Skill 卡片显示名称、状态、版本、操作按钮
- [ ] 草稿可以编辑和发布
- [ ] 已发布可以下架和发布新版本
- [ ] 已下架可以删除或重新上架
- [ ] 操作后有反馈提示
